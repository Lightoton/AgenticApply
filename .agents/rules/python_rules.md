# AgenticApply Python Engineering Rules

## 1. Архитектура и стандарты Python
- Проект построен на асинхронной агентной архитектуре (Python 3.12+).
- Все обращения к внешним API (Telegram, AI сервисы, базы данных) должны быть строго асинхронными (`async def` / `await`).
- Логирование: использовать встроенный модуль `core.logger`, исключать bare `print()` в продакшен-коде.

## 2. Петля верификации Python (Verification Loop)
Перед завершением задачи по данному репозиторию:
1. Выполнить проверку байт-компиляции и синтаксиса для каждого измененного `.py` файла:
   `python -m py_compile <path/to/modified_file.py>`
2. Если изменения затрагивали `core/config.py` или структуру базы данных, проверить парсинг окружения:
   `python -c "from core.config import settings; print('Config OK')"`
3. Если запущен локальный стек: убедиться, что `docker compose ps` возвращает статус healthy.

Запрещено отдавать задачу как выполненную при наличии синтаксических ошибок или непроверенных импортов.
